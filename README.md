# Business Intelligence Portfolio — ALY 6060

A portfolio of **decision-support and business-intelligence** projects built with **Tableau, Qlik Sense, and BI case-study analysis**, completed for **ALY 6060: Decision Support & Business Intelligence** at Northeastern University (Fall 2024). Each module pairs a business question with interactive dashboards and a written analysis translating data into decisions.

## Modules

| # | Topic | Tools | Focus |
|---|-------|-------|-------|
| **1** | [Analytics & Influencing](01-analytics-and-influencing) | Tableau | Market & stock-data visualization to influence decisions |
| **2** | [Stakeholder Involvement](02-stakeholder-involvement) | Excel / Analysis | Climate impact on mental health & workplace productivity |
| **3** | [Working with Business Partners](03-business-partners-qlik) | **Qlik Sense** | Fortune 1000 & Top-10-CEO dashboards |
| **4** | [Implementing Embedded Analytics](04-embedded-analytics) | Tableau | Embedding analytics into business workflows |
| **5** | [PayPal Fraud Case Study](05-paypal-fraud-case-study) | Tableau | Fraud-driver analysis (H2O Driverless AI case study) |
| **6** | [Signature Assessment](06-signature-assessment-att) | Tableau + PPT | AT&T data-analytics culture & sales dashboards |

## Skills Demonstrated

- **BI & Dashboarding** — Tableau and Qlik Sense dashboard design, interactivity, and drill-downs
- **Decision support** — framing business questions and translating data into recommendations
- **Data storytelling** — communicating insight to stakeholders and leadership
- **Embedded & self-service analytics** — designing analytics for non-technical business users
- **Case-study analysis** — fraud detection, data governance, and enterprise data culture

## Repository Layout

Each module folder contains the dashboard workbook (`.twb`), supporting dataset where shareable, the written report (`.pdf`), and a presentation deck where applicable.

> **Note on data:** The PayPal module (05) uses a transaction dataset exceeding 1 GB, which is too large to host on GitHub. The Tableau workbook, written analysis, and the H2O case study are included; see that module's `DATA_SOURCE.md` for the original source.
