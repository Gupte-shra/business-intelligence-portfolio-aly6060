# Data Source — PayPal Fraud Case Study

The transaction dataset used for this analysis exceeds GitHub's 100 MB file limit
(the raw transactions file is ~1.2 GB), so it is **not stored in this repository**.

## What's included here
- `paypal_fraud_dashboard.twb` — the Tableau workbook analyzing fraud drivers
- `report.pdf` — written analysis and recommendations
- `h2o_paypal_case_study.pdf` — the H2O Driverless AI / PayPal customer case study

## Dataset
The analysis used a financial transactions dataset (transactions, users, cards, and
fraud labels). Comparable public financial-transaction / fraud datasets are available on
Kaggle and similar open-data platforms. To reproduce the dashboard, point the Tableau
workbook's data source to your local copy of the transaction files.
